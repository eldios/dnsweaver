A small bridge between moving parts.

Let the labels
do the typing.

Your workloads already have names. Read them from Traefik, Caddy, nginx-proxy or native labels. Connect Kubernetes, Proxmox VE or Incus too. Run the sources you need together.

Domain rules select the DNS providers. dnsweaver creates and updates the matching records, then reconciles changes as workloads come and go. You choose the ownership and cleanup policy.

Cleanup is a policy
you choose.

Managed mode tracks ownership and removes owned records according to your cleanup settings. Additive mode creates records without deleting them.

ManagedOwnership-aware cleanup
AdditiveCreate without deleting
Dry runInspect planned changes

Authoritative mode can delete unrecognized records. Use it only for a zone dedicated to dnsweaver. Read the mode guide.
